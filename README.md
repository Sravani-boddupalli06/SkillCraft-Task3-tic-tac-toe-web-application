# Tic Tac Toe Web Application

A simple and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**.  
This project is created as part of the **SkillCraft Technology Internship Task**.

---

## Objective

Build a functional Tic Tac Toe game where two players can play by taking turns, and the system detects win or draw conditions.

---

## Features

- 2 Player game (X and O)
- Interactive 3x3 grid board
- Turn-based gameplay system
- Win detection (rows, columns, diagonals)
- Draw detection
- Restart game functionality
- Simple and responsive design

---

## Technologies Used

- HTML – Structure
- CSS – Styling and layout
- JavaScript – Game logic and interactivity
